## Перенос дизайна из источника

В рамках данного чата мы будем переносить некоторые элементы дизайна из сверстанной страницы public/design_pattern/garnd_kg_html_kopilot/index.html (далее по тексту донор)

Стили этой страницы описанны в файле public/design_pattern/garnd_kg_html_kopilot/assets/css/styles.css

Основные файлы стилей проекта лежат в директории public/scss. При переносе переводи стили в scss используй вложенность.

В осоновных стилях есть файл с переменными public/scss/\_vars.scss. Можешь вносить изменения в этот файл менять значения переменных при переносе.

При переносе используй используй семантическую верстку.

При переносе оптимизируй html при необходимости удаляй лишние обертки и т. п. Учитывай требования accessibility.

## Перенос шрифта

Проанализируй страницу и стили найди все толщины шрифта Montserrat и подключи их в файл основных стилей проекта public/scss/\_fonts.scss
