Создай отдельный блейд компонент который будет выводить шапку внутренней страницы данного сайта. Внутри компонета должна быть стандартная секция вложенным контейнером в ней выводится заголовок h1, значения для h1 передаются по средствам параметра.

Внешнее оформление компонета следующее:

Секция имеет фоновое изображение, которое надо взять из файла @public/img/about-banner.webp это значение по умолчанию, так же нужно предусмотреть возможность передавать путь к изображению через параметр.

Заголовок h1 должен быть по левому краю контейнера и иметь белый цвет.

Стили этой го компонета положи в файл @public/scss/\_header.scss.

Данный компонент сразу подключи в шаблоне В шаблоне @resources/views/contacts.blade.php

Давай отккорректируем стиль созданного компонета:

стиль псевдо класса :after сделай таким же как у класса .hero::after

Не назначай минимальную высотуэтой секции.

В шаблоне @resources/views/contacts.blade.php создай секцию в которую выведи основные контакты из таблицы контактов. Секцию размести после хлебных крошек. Для вывода используй информацию из этого источника https://github.com/asmi046/site_skelet/blob/master/tutorials/contacts.md этот функционал уже реализован в проекте.

Структура шаблона:

Секция разделена на 2 столбца в левом выводятся текстовые данные а в правую часть нужно вывести карту. Для карты используй компонент:

```php
<x-map.map-in-page name="Денталика" :geo="$contacts['geo']" :adres="$contacts['adress']" :phone="$contacts['phone']"></x-map.map-in-page>
```

ПОдставь в него значения из таблицы контактов, которые ты получаешь в контроллере.
